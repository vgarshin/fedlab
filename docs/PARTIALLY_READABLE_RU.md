# Флаг PARTIALLY_READABLE: что означает и когда ставится

**Для кого:** жюри и сотрудники лаборатории, которые смотрят результаты проверки.
**Главное:** флаг информационный — на оценку не влияет и ни одну работу не снимает.

## Зачем он нужен
Иногда в презентации часть слайдов — обычный текст, а часть — «картинки» (сканы, вставки экранов): текстового слоя в PDF там нет. Такая работа может пройти техническую проверку (текста суммарно хватает) и получить незаслуженно низкий балл — или, наоборот, после распознавания (OCR) внезапно «выправиться». Раньше система об этом молчала. Теперь такие работы помечаются флагом `PARTIALLY_READABLE` с номерами слайдов.

## Критерии (как система решает)
* **Слайд без текста**: в текстовом слое PDF на слайде меньше 5 знаков после нормализации пробелов **или** слой «мусорный» — больше 5% нечитаемых символов (обрывки вида `(cid:12)`, управляющие символы). Именно эти слайды система отправляет на OCR.
* **Флаг ставится**, если в работе есть **и** обычные слайды, **и** слайды без текста (хотя бы по одному).
* К сообщению добавляется судьба этих слайдов:
  * `OCR recovered [3, 7]` — слайды распознаны, текст получен;
  * `no text for [9]` — текста так и нет (OCR выключен для запуска, превышен лимит слайдов или бюджет, либо OCR ничего не вернул).

## Когда флаг НЕ ставится
| Ситуация | Что вместо этого |
|---|---|
| **Все** слайды без текста, OCR выключен или не помог | `NOT_MACHINE_READABLE` — работа снята: 0 баллов, ИИ не вызывался |
| **Все** слайды без текста, OCR их распознал | `OCR_PAGES` — перечислены распознанные слайды (это нормальное поведение) |

Пример: работа «WW $WIN» (полностью скан) → после OCR текст появился, оценка по существу — это штатная работа OCR, флаг не нужен. Работа «ПРИКЛЕП» (122 знака, большая часть слайдов — картинки) → до OCR прошла фильтр и была снята оценивающей моделью за бессодержательность; теперь видно почему: флаг с номерами слайдов без текста.

## Где смотреть
* **Колонка Flags** в таблице работ запуска — жёлтая пометка `PARTIALLY_READABLE` (наведите курсор — подсказка).
* **Карточка работы** → блок «Technical pre-check»: полное сообщение с номерами слайдов.
* **Файлы результатов**: пометка попадает в `technical_warnings` (итоговый CSV для жюри и файлы обратной связи).

## Важно
* Флаг **не влияет на баллы**: оценивающая модель его не видит (как и пометки о манипуляциях).
* Флаг **не** означает «снять с оценивания» и **не** включает пометку «нужна ручная проверка» — это только информация для человека.
* Слайды без текста, распознанные OCR, помечаются отдельно (`OCR_PAGES`) — это разные подсказки: одна про исходное состояние файла, другая про распознавание.
